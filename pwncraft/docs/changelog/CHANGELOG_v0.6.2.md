# pwncraft v0.6.2

## 启动与单窗口

- 新增 `SingleInstanceController`，使用 `QLockFile + QLocalServer` 保证同一用户只运行一个 pwncraft实例。重复启动时只向已有进程发送 `activate`，然后退出。
- 移除启动阶段的模态任务引导弹窗。首次运行直接打开主窗口内的“任务”页，配置保存后返回 EXP。
- 修复 Heap 画布中 `warnings` 和“手动画布”两个隐藏 QLabel 无 parent，在刷新时被 `setVisible()` 变成 Windows 顶层小窗口的根因。它们现在绑定画布容器并始终隐藏。
- 任务配置保存到 `QSettings task/profile_json`，后续启动直接使用已校验的架构、libc、文件路径和 IO 变量。
- 运行记录从独立 `QDialog` 改为主窗口内的 Bottom Dock，禁止浮动；启动时不显示，用户点击后在同一窗口内展开。

## 布局和按钮语义

- 顶部改为 `EXP / 堆图 / 任务` 三段式导航，取消重复的“任务设置”和全局“工具栏”按钮。
- `EXP 工具` 开关移入 EXP 标题栏，与“复制全部/更多”处于同一上下文；紧凑窗口仍默认收起，恢复宽度后尊重用户开关偏好。
- 任务页使用目标环境、本题文件、EXP 习惯三张卡片，仅保留“保存并返回 EXP”一个主操作。
- Heap 操作表单只保留“添加为下一步”；更新、删除、拆分和合并统一回到时间线双击/右键，防止表单和源码顺序冲突。
- 画布手工层仅常驻“从选中载入/覆盖当前 chunk”，添加假设 chunk 和清除收入“更多手工层操作”菜单。

## 版本

- 应用版本更新为 v0.6.2。
