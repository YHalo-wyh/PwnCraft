# pwncraft v0.6.5

## 恢复 v0.5 工作区

- 主窗口恢复 v0.5 的左右 + 下方布局：左侧任务/代码工具，右侧 EXP，底部日志常驻。
- 左侧工具名称恢复为 `代码块 / 进制转换 / 格式化字符串 / 命令提示 / GDB菜单`。
- EXP 页继续使用“复制全部 / 保存 .py / 清空”的直接操作方式。
- HeapViz 恢复 v0.5 的 4:7 双栏：左侧上方完整 EXP、左侧下方语义控制区、右侧 Heap/Bin 画布。

## 非 AI 语义操作

- `语义操作` 默认打开，alloc/free/edit/show、更新步骤和删除步骤不依赖 AI。
- `自定义 Chunk / 函数适配 / 利用路线 / Pwndbg 校准 / 同步时间线 / Bin 文本 / 当前步骤细节` 全部常驻在 EXP 下方。
- AI 仅作为最后一个 `AI 校正` 页签；打开 AI 不会隐藏、移除或替换传统语义操作。
- 宽表单与 AI 页使用内部滚动，避免把 EXP 压缩到不可编辑高度。

## 保留的现代能力

- 保留 AST 变体识别、严格 allocator、MemoryRegion、七列时间线、人工校正和 LM Studio 手动分析。
- 保留单实例、多余顶层小窗口修复、任务配置持久化和高 DPI 缩放。

## 版本

- 应用版本更新为 v0.6.5。
