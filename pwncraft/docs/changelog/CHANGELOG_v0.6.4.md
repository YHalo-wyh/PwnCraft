# pwncraft v0.6.4

## 回归更早的工作区布局

- 主窗口恢复 v0.6.0 时期的结构：左侧固定工具侧栏，右侧原生 `Exp 编辑 / 堆可视化` 页签，底部为可展开运行记录。
- 左侧恢复品牌卡、任务上下文和 `代码块 / 转换 / Fmt / 命令 / GDB` 横向页签，不再使用全宽顶部导航或纵向工具导航。
- EXP 标题栏恢复明确的“复制全部 / 保存 .py / 清空”按钮。
- HeapViz 恢复 `42% EXP / 58% Heap/Bin` 主区域、底部语义时间线抽屉和右侧 AI 校正抽屉。
- HeapViz 顶栏恢复 heap base、地址类型、插入 chunk 地址、时间线/校正、AI 校正和场景操作。
- 运行记录恢复在主窗口底部展开，不创建独立日志窗口。

## 保留的新能力与修复

- AST 代码识别、严格 allocator、MemoryRegion、时间线人工校正、LM Studio 手动分析、提示预算和规则学习保持当前实现。
- 保留单实例锁，重复启动只唤起已有窗口。
- 保留 HeapViz 隐藏标签父子关系修复，启动后不会再出现多个无标题小窗口。
- 已保存任务配置时直接进入主窗口；首次使用才显示引导。

## 版本

- 应用版本更新为 v0.6.4。
