# pwncraft v0.5.0 更新日志

## 这次主要改了什么

### 1) UI 风格升级（HarmonyOS 灵感，但不做花里胡哨）
- 重做全局主题：更浅的工作台、更统一的留白、更清晰的主次层级。
- 主按钮改成蓝青渐变，次级按钮/危险按钮/芯片按钮分工更明显。
- Tab、表格、滚动条、日志框、代码区、Heap 画布整体统一成更现代的卡片式风格。
- 首页侧边栏新增 Hero 顶部卡片，信息密度更高但入口更清爽。

### 2) HeapViz 交互升级
- 新增 **新手引导 / 进阶控制** 两种界面模式：
  - 新手模式默认收起部分高阶入口，降低认知负担；
  - 进阶模式保留函数适配、Pwndbg 校准等完整能力。
- 可视化区域新增摘要胶囊：
  - 当前模式
  - chunk 数量
  - handle 数量
  - warning 数量
  - 当前 focus chunk
  - 手动画布层数量
- Heap 画布顶部新增 step 摘要 banner。
- 缩放按钮改成更轻量的芯片式按钮。

### 3) “多元化 / 自定义”改进：新增自定义 Chunk 画布层
- 新增 **“自定义 Chunk”** 面板。
- 支持：
  - 从当前选中 chunk 载入字段；
  - 覆盖当前 chunk 的显示字段；
  - 额外叠加一个“假设 chunk / fake chunk / 教学 chunk”。
- 这些操作明确标记为 **manual overlay / assumed**：
  - 不篡改真实 glibc allocator 推导；
  - 只影响当前步的画布展示和解释文本；
  - 适合讲解思路、画 fake chunk、补充 stale / overlap / poisoning 说明。

### 4) 小白友好改进
- 语义操作新增 quick chips：alloc / free / edit / show。
- 新手模式下默认压缩高级入口，避免一上来就被过多功能淹没。
- 自定义 chunk 面板增加教学提示，引导先跑真实状态，再叠加思路层。

## 没有动歪的底线
- 严格模式下仍然以 **真实 glibc 物理驱动** 的模拟为准。
- 手动画布层不会偷偷改变 allocator 结果，不会把“教学图”伪装成“真实状态”。
