# pwncraft v0.6.3

## 经典布局回归

- 主界面恢复 `EXP 编辑 / 堆可视化` 双工作区，不再把任务配置作为第三个常驻页面。
- 顶部恢复独立的“工具栏”“显示比例”“任务设置”，EXP 编辑器标题区只保留复制和文件操作。
- 堆可视化模式继续使用左侧完整 EXP、右侧 Heap/Bin 画布，并隐藏积木库和底部状态。
- 任务设置恢复为按需打开的引导式对话框；已保存配置的启动过程不再重复打开。
- 运行记录恢复为显式打开的独立窗口，默认不显示，不占用工作区高度。
- 操作页恢复添加、更新、删除当前步骤；手动画布恢复清晰的两行按钮布局。

## 保留的稳定性修复

- 保留进程单实例锁；重复启动只唤起已有主窗口。
- 修复 HeapViz 隐藏状态标签没有父控件、调用 `setVisible` 后变成多个顶层小窗口的问题。
- 保留 v0.6.1 的高 DPI、响应式布局、AST/allocator、LM Studio 手动分析和 AI 校正能力。

## 版本

- 应用版本更新为 v0.6.3。
