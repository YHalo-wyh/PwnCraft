用户反馈两项调试终端体验问题（附截图）：① 内容已滚到底部，执行光标却画在顶部历史行；② 选中复制需要右键菜单，不顺手。

## 光标跟随修复

- 根因：`_live_prompt_position()` 在当前行找不到提示词时会从**可见滚动缓冲**里搜最后出现的 `pwndbg>` 文本——题目程序接管后（如 `gateway>` 菜单），这条兜底会命中历史里的旧 `pwndbg>` 行，把光标钉在视口顶部。
- 修复：删除文本搜索兜底，光标改为**直接信任 PTY 真值 `screen.cursor`**（与所有终端一致），仅在用户滚入历史时隐藏（保持既有的查看历史行为）。新增 `_caret_position()`。

## cmd 体感的选择复制

- **拖选松开即复制**（快速编辑体感）；原地单击（起=终）不复制，不污染剪贴板。
- **右键智能切换**：有选区 → 复制并清除高亮；无选区 → 直接粘贴（经典 cmd 右键行为）。两种情况都不再弹菜单。
- **双击选词 / 三击选行**，选中即复制。多击判定用单调时钟（`event.timestamp()` 在部分合成/离屏路径恒为 0，会永久破坏多击检测）。
- **键盘**：有选区时 `Enter`=复制并清除、`Esc`=取消；其余普通按键先清除选区再正常处理；`Ctrl` 组合不受影响——保留既有 `Ctrl+C`（有选区复制 / 无选区 SIGINT）与 `Ctrl+V` 粘贴。
- 新增 `clear_selection()` 等辅助；右键菜单保留为兜底（复制/粘贴/全选），被右键直接处理时抑制。
