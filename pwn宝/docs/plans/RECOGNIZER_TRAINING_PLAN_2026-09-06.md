# PwnCraft 识别器能力建设目标与训练方案

日期：2026-09-06。状态：规划草案，未替换现有锁定训练协议。

训练定义：以独立金标准为验收依据，通过偏差定位、通用实现修正和跨题回归，持续建设程序行为识别、状态解释与可视化能力。每轮交付物包括可核对的能力增量、实现差异、测试和证据。模型权重微调不属于当前主线。

## 现状与判断

当前工程具备较好的堆语义基础，训练框架已发展到 comparator v4.1，但跨领域验收和通过口径仍需补齐。近期投入优先用于验收可信度、公共语义能力和栈领域接入。

| 核实对象 | 当前事实 | 对规划的影响 |
|---|---|---|
| 语料清单 | corpus 下 21 份 manifest：堆 8、stack_rop 10、fmtstr 3，均标为 GOLD；架构为 amd64 16、x86 5 | 已有跨领域材料，可先清理和接入，再决定补题 |
| GOLD 含义 | 21 份 manifest 的 EXP correctness 均为 UNVERIFIED；13 份非堆 manifest 的 libc_sha256 均为空 | 材料质量、语义标注和行为验证必须分开记录；缺 libc 是否阻塞，应由被验收断言决定 |
| 入口格式 | 堆题 entry_file 为字符串；非堆题为 12 个对象和 1 个空值；适配器直接使用 Path(exp_rel) | 跨域接入先统一 schema 和入口解析，不能只换题目路径 |
| 正式真值 | autocorrect/cases 有 3 个目录，其中 lab13、note2 有 expected_truth；babyheap 保留 expected_analysis | 3 个历史案例不等于 3 道全层通过题 |
| 接受记录 | accepted_cases.json 当前不存在；最近保存的 truth_regression 两题均为 DIVERGED@HELPER_CONTRACT | 已接受规则、已通过断言、整题验收分别注册 |
| 训练入口 | run_case 固定调用 HeapSession.load，比较层包含 ALLOCATOR/BINS | 栈、格式化字符串需要领域适配器和适用层声明 |
| 目标内部行为 | 已有 BehaviorEffectExpander；训练适配器仍按 alloc→一次 malloc、delete→一次 free 导出动作 | 扩展器存在与训练链正确接通分开验收；优先复用现有设施 |
| 栈能力 | 已有 StackState、RegisterState、ROPChain 和相关测试 | 具备基础构件，尚不足以证明任意脚本已能被完整理解 |
| 二进制值流 | x86_trace 明确限定为 AMD64 线性扫描，缺完整控制流和一般别名分析 | 支持范围应明示，范围外结论保持 UNKNOWN |
| 画布比较 | 已有后端模型与真实 JS 渲染计划比对 | 可复用结构化验收思路，但内部一致性不等于独立真值正确 |

以上统计来自当前文件与代码。本轮仅重跑框架合成测试，结果为 8 passed；未重跑全部题目、项目全量测试或目标程序。

## 总体优化目标

建设覆盖堆、栈、格式化字符串、值与地址派生、结构体视图和跨区域状态的证据驱动识别与解释系统。

对输入材料中的每个可支持行为，输出语义、参数、读写范围、对象关系、状态变化及证据来源；对材料缺失、路径不明和实现不支持，分别说明原因。界面中的每个确定结论可回溯到具体输入和版本。

建设目标按五个方面验收：

| 方面 | 目标 |
|---|---|
| 覆盖 | 首期打通堆、栈、格式化字符串三条领域验收链；共享解析、值流、证据和状态标识 |
| 准确 | 同时比较结论及其依据；缺证据、未执行检查和不适用均具有独立状态 |
| 泛化 | 修复依据语义结构；题名、函数名、注释和排版变化不能决定结论 |
| 一致 | 编辑器、分析结果、状态模型和画布使用可关联的事件与状态版本 |
| 稳定 | 有限资源内完成分析；异常和截断形成可复查结果；规则修复不损害既有能力 |

## 阶段 0：建立可信验收边界

这是下一轮扩域前的首要交付。

### 0.1 关闭空验收与缺件通过

当前比较器的内存合成检查结果为：仅提供 case_id 的真值配合空输出，总结果仍为 MATCH，十个层为 MATCH，RENDERER_PLAN 为 SKIPPED。该结果只证明比较器缺少完整性门禁，不代表某一道真实题已经被误验收。

每个案例增加评测契约，声明 required_layers、required_artifacts、required_assertions 和支持环境。对以下情况分别处理：

- MATCH：本项所需材料完整，独立断言实际执行并全部成立。
- DIVERGED：材料足够，实际结果与真值冲突。
- INCONCLUSIVE：缺必需材料、标注或证据，无法判定。
- BLOCKED：依赖的上游结果不可信，本层无法作独立判定。
- NOT_APPLICABLE：领域契约明确不适用，例如普通栈案例的 BINS 层。
- SKIPPED：应执行而未执行的检查；必需项出现此状态阻止整题通过。

逐项记录 planned_assertions、executed_assertions、matched_assertions。空断言集不得获得整题通过资格。未提供必要 run_id 与混合 run_id 均拒绝正式验收。

现有 PHYSICAL_MEMORY 主要检查对象数量，SNAPSHOT 主要检查事件归属。后续补充独立期望的字节范围、值、未知区间和状态变化；对象数量一致只能证明一项结构检查通过。

### 0.2 将回归结果接入真正的门禁

当前 truthregress 会保存失败报告，但函数末尾未按失败结果设置非零退出状态；真值锁检查使用 strict=False，缺少 truth 文件的注册案例还会被跳过。正式入口需对缺锁、缺件和失败返回阻断结果；探索运行保留单独模式。

新增三种注册对象：

- rule_acceptance：某项通用规则经过验收，引用补丁和断言。
- assertion_acceptance：某题某项或某一层已通过，作为后续不得退化的能力。
- case_acceptance：该题约定的全部必需项通过。

保留现有“一轮一个最早偏差”纪律。修复某项契约后，下游仍有已知错误时，可接受规则增量，但整题保持未通过。这样既能持续推进，也不会用整题标签夸大进度。

历史差异解释需关联具体断言、受影响案例和补丁范围，避免只解释整个 op_sequence 等宽泛维度，就长期豁免该维度中新出现的退化。

### 0.3 固定版本身份

运行清单记录真值版本、源材料哈希、入口、识别器与比较器版本、领域模型及环境配置。保留 run_id 作为一次执行标识，另用可复现 fingerprint 判断同输入同版本的语义一致性。

门禁验收：空输入、缺必需输出、混合或缺失身份、缺少真值锁、失败退出状态、宽泛漂移解释等合成反例均被正确处理；已有框架检查继续通过。

## 阶段 1：公共语义与适配层

采用渐进接入方式，继续保留现有堆实现，通过领域适配器共享以下信息。

| 公共信息 | 内容 | 首期用途 |
|---|---|---|
| CaseManifest | 明确入口、材料角色、架构、环境需求、数据拆分、必需断言 | 兼容现有字符串/对象入口，空入口进入材料待补队列 |
| EvidenceRecord | 来源、位置、证据类型、来源哈希、支持和反对的结论 | 保持 EXP、目标内部行为、观察记录之间的责任边界 |
| ValueRecord | 位宽、端序、常量/符号/未知、依赖、有效期 | 复用 ValueIR、AbstractValue 等已有能力，先定义转换契约 |
| EventRecord | 事件身份、源码位置、调用上下文、父子关系、分支条件 | 表达一次调用对应零个或多个内部行为 |
| StateRecord | 内存区域、对象、别名、寄存器或领域状态、版本 | 让多个视图引用同一事实及其来源 |
| DiagnosticRecord | 最早偏差、阻塞层、缺失证据、实现边界 | 支持训练选题和界面解释 |

适配层先提供 heap、stack、fmt 三种评测入口。领域适用层由契约决定，不能把所有领域硬塞入 allocator 层序。

公共值流训练优先覆盖：调用点接收结果的实际使用、参数绑定、包装调用与别名、长度派生、常量循环、已知与未知分支、状态重置后的过期值。输出若依赖分支假设，应携带该假设。

特别区分源码出现位置与执行事件身份。同一行可出现多个调用，循环也可多次执行同一位置；使用调用位置、调用上下文和迭代身份关联事件，不能依赖 source_line 字典覆盖。比较器目前仍有 ops_by_line 路径，应纳入接入验收。

门禁验收：堆领域已有已接受断言无退化；栈、fmt 的合成材料能完整走通输入、适用层比较和结果导出；未支持领域得到明确结果。

## 阶段 2：分领域能力课程

按语义缺口组织课程，并以题目作为证据载体。每个目标都需要正例、近似反例和不同来源的迁移样本。

| 顺序 | 领域 | 识别与解释目标 | 金标准断言 |
|---|---|---|---|
| 1 | 公共 EXP 语义 | 同步接收与被使用的数据分开；调用参数、返回值和派生值关联 | 调用点、消费者、参数角色、证据归属 |
| 2 | 栈基础 | 栈帧、参数、局部数据、保存状态、字节区间和偏移关系 | 源码/符号或观察记录支持的布局、已知字节、未知边界 |
| 3 | 栈状态 | 给定片段的栈指针变化、寄存器状态、控制数据与普通数据区分 | 状态转移、位宽、对齐结果、无法解释的副作用 |
| 4 | 堆现有缺口 | 一次接口对应多个内部动作；句柄、对象和物理分配分开 | 动作次序与对象身份、生命周期和内存变化 |
| 5 | 格式化字符串 | 输入格式、参数消费、输出计数与副作用语义 | 普通文本/格式语法区分、计数、位宽和证据支持的读写范围 |
| 6 | 值与地址 | 截断、符号扩展、端序、地址归属、派生依赖与过期状态 | 可确定值、歧义集合、依赖来源、失效传播 |
| 7 | 结构与环境 | FILE 等类型化视图、ABI、内存权限、调用约束 | 布局版本、字段解释、可证/不可证条件 |
| 8 | 跨区域解释 | 同一对象、地址和值在多个领域视图中保持身份与版本一致 | 别名一致、观察来源、时间顺序、跨视图断言 |

栈课程优先采用普通函数和受控片段的静态分析或既有观察记录。栈布局、字节覆盖、给定状态解释与完整脚本识别分别计分；界面拥有某个构建工具不能直接计为识别能力已完成。

堆课程沿用现有能力队列。调用点 OUTPUT_DATA_FLOW、size-only 参数形态、目标内部多动作和资源健壮性分别立项；补丁落点由当前最早偏差确定。已有 BehaviorEffectExpander 的接线、来源和身份应先核对，再决定是否增加新实现。

首期支持范围围绕现有 Linux amd64/x86 材料明确划定。ARM、其他 ABI、自定义分配器和内核类材料进入独立候选队列，各自需要匹配的语义模型与真值资源，不能继承已有领域的通过率。

## 阶段 3：金标准数据治理

### 分开材料质量与验收成熟度

保留现有 quality.tier，同时新增：

- material_readiness：该评测所需材料是否齐全。
- annotation_status：未标注、审查中、锁定及修订链。
- oracle_scope：只验解析、值流、目标行为、观察状态还是呈现。
- evaluation_status：未评测、局部通过、整题通过、无法判定。

libc 信息为空时，纯解析或部分栈布局断言仍可能可评测；依赖该环境的断言必须等待材料或保留未知。按断言需求判断材料完整性，统一 GOLD 的解释。

真值来源优先采用独立源码事实、可核对的现有观察记录和外部参考结果。识别器自己的输出和可视化模型仅用于内部一致性检查。AI 草拟标注应记录来源并经过独立复核。

### 拆分防污染

开发集用于查看偏差并修复；迁移验证集用于有限次跨题确认；封存测试集只在里程碑验收时打开。训练设计可从 60%/20%/20% 起步，按案例来源簇划分并尽量保持领域覆盖，不按脚本文件随机拆分。

同一道题、多份解答、镜像仓库、重编译版本和自动改名变体应属于同一来源簇。查看过封存题详细错误并据此修复后，该题进入已曝光集合，以新来源样本补足封存集。仅改函数名的变体证明抗命名依赖，不能单独证明跨题泛化。

当前已用于修复或探测的 babyheap、lab13、note2、wheelofrobots、hacklu、stkof 应记录相应曝光历史；不再将其迁移结果宣传为全新盲测。

### 首批工作量

先对现有 21 份 manifest 做材料、入口和领域资格清点。首批建立堆、栈、fmt 各 2 个可核验样本作为管线验收集；fmt 是否能使用现有材料取决于具体断言需求。这些经过调试的样本统一归入开发集。

门禁和三条验收链稳定后，将第一版标注集扩展到 24—40 个独立来源簇，配合合成边界样本。该数量是工作量规划，不是当前已具备的金标准数；不足以支持统计结论的领域保留计数报告。

## 阶段 4：每轮训练执行方式

1. 依据能力矩阵选一个最早偏差。先处理影响多个领域的公共问题，再处理领域专用问题。
2. 在隔离于识别器输出的输入范围内建立并锁定真值，记录来源簇、断言和支持环境。
3. 生成当前实现的原始结果。静态分析输入作为数据处理，结果产物关联同一次运行。
4. 执行早停比较，确定本轮唯一修复目标；完整层诊断单独用于规划，下游依赖失效时标记 BLOCKED。
5. 保存可恢复检查点，提交一个最小通用修正及必要合成测试。
6. 重新生成受影响结果，依次检查当前断言、已接受断言、历史稳定性、近似反例、迁移样本和资源边界。
7. 记录规则接受或撤回；只有该题全部必需项通过才登记整题接受。
8. 更新能力矩阵：新增了哪些经过证明的语义形态、仍缺哪些证据、下轮最早偏差是什么。

同一轮固定输入、配置和比较器版本。比较器修正与识别器能力修正分开提交、分开说明；评测器版本变化时重新计算可比基线。

这一循环是工程实现与回归验收流程。用于辅助阅读或解释的语言模型记录版本与输入范围，正式门禁依赖结构化断言；核心路径确定后再独立评估模型替换或微调是否有收益。

## 指标与发布门禁

以下为拟议目标，均非当前实测能力。

| 指标 | 定义 | 首版目标 |
|---|---|---|
| 必需断言完成率 | 实际执行的必需断言/计划的必需断言 | 宣称整题通过时必须 100% |
| 已接受断言回归率 | 本轮继续通过的已接受断言/全部已接受断言 | 100%，失败阻断 |
| 语义精确率 | 正确的确定结论/全部确定结论，分领域报告 | 样本充分后争取 ≥95% |
| 语义召回率 | 正确识别的已标注事实/支持范围内可识别事实 | 样本充分后争取 ≥85% |
| 无依据确认 | 没有满足证据要求却输出确定结论的数量 | 发布验收集为 0 |
| 整题通过率 | 全部必需断言通过的案例/冻结评测合同中的全部案例 | 按领域、来源簇报告，通过数量与分母并列 |
| UNKNOWN 分布 | 真值本身未知、输入缺失、实现不支持、路径歧义等分类计数 | 支持范围内因实现不足产生的 UNKNOWN 随里程碑下降 |
| 迁移结果 | 未针对样本修正规则时，独立来源案例的通过情况 | 每个接受规则至少有近似反例；跨题成功另列证据 |
| 重复运行一致性 | 固定输入和版本的语义 fingerprint 一致情况 | 选定基准重复 3 次一致 |
| 资源表现 | 固定设备和规模下耗时 p50/p95、峰值内存、截断率 | 先建立基线；异常和截断不可伪装为成功 |

精确率和召回率同时查看，避免全部输出 UNKNOWN 获得表面高精确率。UNKNOWN 真值不进入已知事实召回分母，但数量必须公开。适用范围和分母在运行前固定，不能在看到失败后缩小。

小样本优先报告“通过 4/6 个独立案例”及失败原因；数据增长后再报告按领域汇总的指标和按来源簇计算的不确定性。自动生成的大量近似变体不增加独立样本数。
